# Case: case_001_vbus_clearance_dogleg

## Tiêu đề
VBUS Via Clearance Conflict vs B.Cu Horizontal Track

## Mô tả kỹ thuật & nguyên nhân
Đoạn dây B.Cu ngang tại Y=94.500mm chạy qua via VBUS tại (80.545, 93.950) bị vi phạm khoảng cách an toàn (0.149999mm < 0.150mm). Sửa đổi: hạ thấp đoạn dây ngang xuống Y=94.700mm tạo bậc thang trực giao đạt 0 lỗi DRC.

## Số lỗi DRC trước sửa: 1
## Số lỗi DRC sau sửa: 0
